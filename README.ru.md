# claude-mode

Моды для **Claude Code** (вкладка Code в десктопном приложении и терминал) на API плагинов с function hooks.

[English version →](README.md)

| Мод | Что показывает |
| --- | --- |
| **usage-band** | Полоса из двух строк над полем ввода: заполнение контекста, загруженные файлы памяти и лимиты подписки (5 часов и неделя) с отсчётом до сброса. |
| **roadmap** | Панель **«Дорожная карта»**: текущая задача и её стадии сверху вниз — контекст → выполнение → проверка → тест → пуш → деплой — по тому, что Claude реально делает; план самого Claude, время этапов и блок «Ранее». |
| **git-branches** | Панель **«Ветки»** в духе GitLens: текущая ветка, опережение/отставание, изменения в рабочей копии, локальные и удалённые ветки, pull request'ы GitHub со статусом проверок и последние коммиты. |

Каждый мод есть на двух языках: [`ru/`](ru) и [`en/`](en). Подключайте один язык на мод — имена плагинов совпадают.

## Установка

Нужен Claude Code **2.1.288** или новее. API function hooks в раннем доступе и может меняться между версиями.

### Терминал

```bash
claude --plugin-dir ./ru/usage-band --plugin-dir ./ru/roadmap --plugin-dir ./ru/git-branches
```

### Десктопное приложение (и все сессии)

Добавьте папки в `CLAUDE_CODE_PLUGIN_DIRS` в блоке `env` файла `~/.claude/settings.json`. Пути абсолютные, через `;` на Windows или `:` на macOS/Linux:

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "C:\\code\\claude-mode\\ru\\usage-band;C:\\code\\claude-mode\\ru\\roadmap;C:\\code\\claude-mode\\ru\\git-branches"
  }
}
```

Перезапустите приложение или откройте новую сессию.

## Использование

| Команда | Действие |
| --- | --- |
| `/roadmap` | Открыть дорожную карту |
| `/roadmap reset` | Начать новую задачу (текущая уйдёт в «Ранее») |
| `/branches` | Открыть панель веток |
| `/branches fetch` | Выполнить `git fetch --all --prune` и обновить |

Полоса над полем ввода появляется сама, без команды.

### Как работает дорожная карта

- Каждый новый запрос — новая задача. Короткие подтверждения («да», «давай», «продолжай»…) продолжают текущую.
- Стадии определяются по вызовам инструментов: чтение и поиск → **Подготовка контекста**; правки и прочие команды → **Выполнение**; `tsc`, линтеры, `validate`, `build` → **Проверка**; `npm test`, `pytest`, `jest`… → **Тест**; `git commit` / `git push` → **Пуш**; `vercel`, `netlify`, `wrangler`, `docker push`… → **Деплой**.
- Стадии подстраиваются под проект: **Пуш** — только в git-репозитории, **Деплой** — только если есть настройки деплоя (`vercel.json`, `Dockerfile`, `.github/workflows`…), **Проверка** и **Тест** — только если они есть в проекте. Если стадия всё же случилась, она показывается всегда.
- Если Claude ведёт список шагов, он появляется под **Выполнением** со своим прогрессом.

### Что нужно панели веток

- `git` в `PATH`.
- Для pull request'ов — [GitHub CLI](https://cli.github.com/) с входом (`gh auth login`). Без него ветки и коммиты всё равно видны.
- Панель ничего не меняет в репозитории, кроме кнопки **Fetch**.

## Ограничения

- Где разместить панель, решает приложение: мод не может прикрепить её к нужной стороне или добавить пункт в меню приложения.
- У каждого мода есть тесты: `claude plugin test ru/roadmap`.

## Структура

```
ru/  usage-band  roadmap  git-branches   русские версии
en/  usage-band  roadmap  git-branches   английские версии
```

В каждом моде: `.claude-plugin/plugin.json`, `hooks/hooks.json`, `hooks/register.tsx`, `hooks/register.test.tsx` и `types/index.d.ts`, если мод хранит состояние.
