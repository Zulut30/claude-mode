# 🎛️ command-deck — главные команды в один клик

Панель «Команды»: основные слэш-команды Claude Code, зачем каждая, и кнопка ▶, которая запускает команду так, будто вы её набрали.

```
◐ КОНТЕКСТ И ПАМЯТЬ                                     4
  /compact                                              ▶
  Сжать переписку, освободить контекст
  /clear                                                ▶
  Начать заново: переписка очистится

◇ ПРОЕКТ И КОД                                          3
  /init                                                 ▶
  Создать CLAUDE.md с описанием проекта

◷ СЕССИЯ                                                5
▣ НАШИ ПАНЕЛИ                                           3
/ ВСЕ ОСТАЛЬНЫЕ                                        41
  Показать 41
```

- **Группы:** контекст и память (`/compact`, `/clear`, `/context`, `/memory`), проект и код (`/init`, `/review`, `/code-review`, `/security-review`), сессия (`/cost`, `/usage`, `/resume`, `/export`, `/model`), панели модов (`/roadmap`, `/branches`, `/inspector`).
- **Показывается только то, что есть** в вашем Claude Code; команды плагинов находятся по имени (`/engineering:code-review`).
- **▶ запускает команду** обычным путём, как из поля ввода. `/clear` и `/exit` сначала спрашивают подтверждение. Если команда что-то ответила или не запустилась — всплывающее сообщение.
- **Все остальные** команды — свёрнутым списком по алфавиту, с их собственным описанием.

**Команды:** `/deck` — открыть панель. Она открывается сама при старте сессии.

**Читает:** список команд Claude Code. **Запускает** команды только по вашему нажатию ▶. **Сеть:** нет.

Установка — в [общем README](../../README.ru.md#установка).
