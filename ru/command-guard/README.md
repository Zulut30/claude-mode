# 🛡️ command-guard — страховка от опасных команд

Прежде чем Claude выполнит команду, после которой что-то пропадёт безвозвратно, мод останавливает её, показывает, что именно будет потеряно, и спрашивает вас.

```
Страховка
Claude хочет: rm -rf build node_modules
• build — папка: 214 файлов, 3,8 МБ
• node_modules — папка: ≥ 2 000 файлов, ≥ 96 МБ (посчитано не всё)

  1. Выполнить
  2. Отмена
```

- **Что ловит:** рекурсивное удаление (`rm -r`/`-rf`/`--recursive`, `Remove-Item -Recurse`, `rmdir /s`, `rd /s`, `del /s`), `git push --force`/`-f`/`+ветка`/`--force-with-lease`, `git reset --hard`, `git clean -f`, `git checkout -- .`/`git restore .`, `git branch -D`, `git stash drop`/`clear`. Обычный `rm file.txt` без `-r` — не повод спрашивать.
- **Смотрит на саму команду**, а не на текст: `echo "rm -rf /"`, сообщение коммита, тело heredoc и комментарии не считаются. Цепочки `&&`, `;`, `|`, `sudo`/`xargs`, `bash -c`, `cmd /c`, `$(…)` и блоки PowerShell разбираются; `cd папка && …` и `git -C папка` учитываются.
- **Что пропадёт:**
  - удаление — для каждого пути: файл или папка, сколько файлов и сколько места; ⚠ если это корень диска, вся домашняя папка или папка с вашим проектом. Путь с переменной или маской (`$TMP/x`, `*.log`) — «не могу посчитать заранее»;
  - force push — коммиты на remote, которых у вас нет (число и первые три); про `--force-with-lease` сказано, что это форма безопаснее;
  - `reset --hard`, `checkout -- .`, `restore .` — файлы с незакоммиченными правками и сколько строк пропадёт;
  - `clean -f` — что удалит, по пробе `git clean -n` с теми же ключами;
  - `branch -D` — коммиты, которых нет ни на remote, ни в текущей ветке;
  - `stash drop`/`clear` — какие записи stash пропадут.
- **Выполнить** — команда идёт дальше как обычно. **Отмена** — команда не выполняется, а Claude получает причину («Отменено: …») и не повторяет её вслепую; можно ответить и своими словами — Claude получит ваш ответ. Справа вверху мелькнёт всплывашка, что команда не выполнена.
- **Спросить некого** (запуск `claude -p`, вопрос закрыли) — команда не выполняется: безопасный ответ по умолчанию.
- **Не мешает:** подсчёт не дольше 5 секунд и не больше 2 000 записей / 6 уровней папок; безопасные команды проходят без вопроса и без задержки. Вызовы Bash, которые делают другие моды, не трогает — только команды самого Claude и его субагентов.

**Команды:** `/guard` — состояние, `/guard off` — выключить (запоминается между сессиями), `/guard on` — включить.

**Читает:** размеры файлов и папок, которые команда удалит. **Запускает:** только чтение git — `git log`, `git status`, `git diff --shortstat`, `git clean -n`, `git stash list` (без блокировки индекса, с таймаутом 5 с). **Сеть:** не использует — force push сравнивается с тем, что git знает после последнего fetch. **Хранит:** только флаг «выключено» в хранилище Claude Code.
