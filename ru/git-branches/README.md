# 🌿 git-branches — ветки в духе GitLens

Панель «Ветки»: текущая ветка и её синхронизация, остальные ветки, pull request’ы GitHub, последние коммиты и ветки на сервере.

```
⎇ acme/site · main                                  ↻  ⇣
 ↑2 не запушено   ✎ 3 изменения   обновлено только что

⎇ ВЕТКИ                                               2
  feature/login                       ↓5  #12   АН  2 д
  wip                                  локальная  ИП 10 мин

⇄ PULL REQUESTS                                       1
  #12 Страница входа                       одобрено  ✓

◉ КОММИТЫ                                             8
  a1b2c3d fix: шапка                             ИП  3 ч
  f0f0f0f init                                   АН 30 ч

◌ НА СЕРВЕРЕ                                          1
  Показать 1
```

- **Шапка** — репозиторий и текущая ветка; плашки: сколько не запушено и не подтянуто, есть ли незакоммиченные изменения.
- **Ветки** — по свежести; справа отставание/опережение, номер PR, «удалена на сервере» или «локальная», автор и время.
- **Pull requests** — открытые PR с решением ревью и состоянием проверок (✓ ✗ ●).
- **Коммиты** — граф последних коммитов, HEAD отмечен зелёным, у авторов цветные аватары с инициалами.
- **На сервере** — ветки, которых нет локально; свёрнуты, пока не нажмёте «Показать».
- Пустые разделы не рисуются — вместо них одна тихая строка.

**Бережёт ресурсы:** git запускается только пока панель открыта (после ответа Claude и раз в 3 минуты), список PR берётся из сети не чаще раза в 5 минут (↻ и `/branches` обновляют сразу), статус читается без блокировки индекса. Если папка сессии не git, мод находит проект в её подпапке.

**Команды:** `/branches` — открыть и обновить, `/branches fetch` — сначала `git fetch --all --prune`. Панель открывается сама в git-проекте.

**Запускает:** `git for-each-ref`, `git status`, `git log`, `git remote`; `gh pr list` для PR; `git fetch` — только по кнопке ⇣. **Сеть:** `gh` обращается к GitHub от вашего аккаунта, `fetch` — к вашему remote. Без [GitHub CLI](https://cli.github.com/) всё работает, кроме PR.
