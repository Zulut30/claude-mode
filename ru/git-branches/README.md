# 🌿 git-branches — ветки в духе GitLens

Панель «Ветки» для репозитория, в котором открыта сессия.

```
acme/site                            [ ↻ Обновить ] [ ⇣ Fetch ]
обновлено 1 мин назад · открыть на GitHub

● main                                         ↑2 не запушено
  ✎ 2 изменено · 1 новый

ВЕТКИ · 3
○ feature/login                              ↓5  #12   2 д
  b2c3d4e feat: вход
PULL REQUESTS · 1
✓ Страница входа                                        #12
  feature/login · проверки прошли · одобрено
КОММИТЫ · main · 8
│ a1b2c3d fix: шапка                                    3 ч
```

- **Текущая ветка:** синхронизирована ли с сервером (↑ не запушено, ↓ не подтянуто, не опубликована) и что изменено в рабочей копии.
- **Ветки:** опережение и отставание, «нет на сервере», «только локально», номер PR и статус его проверок, последний коммит.
- **Pull requests:** открытые PR со статусом проверок и ревью. Нужен [GitHub CLI](https://cli.github.com/) с входом (`gh auth login`).
- **На сервере:** ветки, которых нет локально. **Коммиты:** последние коммиты текущей ветки.
- В каждой секции 5 строк и кнопка «Ещё N». Названия веток, PR и хеши коммитов — ссылки на GitHub.

**Команды:** `/branches` — открыть, `/branches fetch` — `git fetch` и обновить. В git-проекте панель открывается сама. Обновляется после каждого хода Claude и раз в 3 минуты.

**Запускает:** `git for-each-ref`, `git status`, `git log`, `git remote`, `gh pr list`; `git fetch --all --prune` — только по кнопке **Fetch**. Больше ничего в репозитории не меняет. **Сеть:** `gh` обращается к GitHub от вашего аккаунта, `fetch` — к вашему remote.
