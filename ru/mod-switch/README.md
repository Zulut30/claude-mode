# 🎛️ mod-switch — переключатели модов

Панель «Моды»: включить и выключить остальные моды одной кнопкой, не вспоминая их команды. Открывается командой `/mods` — сама при старте не появляется.

```
◈ ПОДСКАЗКИ И ЗАЩИТА
  Дальше                                     ● Вкл
  после ответа — цель и 2–3 следующих запроса; о…
  Страховка                                 ○ Выкл
  спрашивает перед rm -r, push --force, reset --hard

▤ ПОЛОСА НАД ВВОДОМ
  Контекст                                   ● Вкл
  Память                                     ● Вкл
  Лимиты                                     ● Вкл
  Скорость                                  ○ Выкл
  Кэш                                        ● Вкл

◇ ДОРОЖНАЯ КАРТА
  Где показывать                        ▣ В панели
  в панели — вкладкой сбоку, под чатом — полосой…
```

- **Подсказки и защита** — «Дальше» (next-steps) и «Страховка» (command-guard): включить или выключить, под каждой — одной строкой, что она делает.
- **Полоса над вводом** — свой переключатель у каждой колонки usage-band: контекст, память, лимиты, скорость, кэш. Скрытая колонка не занимает места, остальные делят ряд поровну.
- **Дорожная карта** — где её показывать: в панели сбоку или полосой под чатом.
- **Кнопка справа** показывает, что сейчас: ● Вкл (зелёным) или ○ Выкл (серым). Нажатие переключает.
- **Каждый мод — хозяин своих настроек.** Панель ничего не хранит и сама не меняет: она запускает команду мода (`/next off`, `/guard on`, `/band hide cache`, `/roadmap band`), как если бы вы набрали её сами, — мод меняет и запоминает значение. Ответ команды виден в чате; всплывашка — только если команда не сработала.
- **Состояние живое.** Переключили командой вручную — панель обновится сама.
- **Не установленные моды** — без переключателей, одной строкой внизу: «Не установлены: command-guard». Колонки полосы переключаются с usage-band 0.4 — в нём появилась команда `/band`.
- Длинные подписи обрезаются по ширине панели, а не переносятся на вторую строку.

**Команды:** `/mods` — открыть панель.

**Читает:** список команд Claude Code (по нему видно, какие моды установлены) и значения самих модов: включены ли «Дальше» и «Страховка», какие колонки полосы скрыты, где дорожная карта. **Запускает:** только команды этих модов — `/next`, `/guard`, `/band`, `/roadmap`. **Сеть:** не использует. **Хранит:** ничего.

Установка — в [общем README](../../README.ru.md#установка).
