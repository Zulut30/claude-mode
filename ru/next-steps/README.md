# ➡️ next-steps — где мы и что дальше

После ответа Claude над полем ввода: цель сессии, чего Claude ждёт от вас, и 2–3 вероятных следующих запроса.

```
◆ Страница входа с проверкой пароля     ⏳ ждёт вас: подтвердить удаление token-speed
ДАЛЬШЕ [ 1 · Да, удали папку token-speed ] [ 2 · Запусти тесты логина ] [ 3 · Открой PR ] ✕
```

- **Цель** — общая задача сессии в нескольких словах. Держится между запросами и меняется, только когда задача действительно сменилась.
- **Ждёт вас** — жёлтым, если Claude чего-то от вас ждёт: ответа на вопрос, подтверждения, проверки руками.
- **Клик по кнопке** или цифра **1–3** в пустом поле вставляет его черновиком. Сам он не отправляется: поправьте и нажмите Enter.
- **0** или ✕ убирает строку. Новый запрос тоже её убирает; пока Claude работает, её не видно.
- Подсказки — от вашего лица, на вашем языке и про то, что только что произошло: файл, тест, функция. Если Claude закончил вопросом или предложением, первая подсказка — согласие с ним; уже сделанное не предлагается.
- Кнопки делят ширину поровну; если совсем тесно — переносятся на вторую строку.

**Расход:** один вызов Haiku после каждого ответа длиннее 40 символов — цель, «ждёт вас» и подсказки приходят в нём вместе: примерно 2–3 тысячи токенов на входе и до 300 на выходе. Не вызывается после коротких ответов, ходов субагентов и пока работают фоновые агенты.

**Команды:** `/next` — состояние, `/next off` — выключить (Haiku больше не вызывается, запоминается между сессиями), `/next on` — включить.

**Читает:** последние сообщения сессии. **Сеть:** вызов Haiku через Claude Code — тот же аккаунт и тот же API, что у самого Claude Code. **Хранит:** только флаг «выключено» в хранилище Claude Code.

Установка — в [общем README](../../README.ru.md#установка).
