# ➡️ next-steps — что спросить дальше

После ответа Claude над полем ввода появляются 2–3 вероятных следующих запроса.

```
ДАЛЬШЕ  1 · Запусти тесты логина   2 · Добавь проверку в signup.ts   3 · Открой PR   0 · скрыть
```

- **Клик по запросу** или цифра **1–3** в пустом поле вставляет его черновиком. Сам он не отправляется: поправьте и нажмите Enter.
- **0** или «скрыть» убирает строку. Новый запрос тоже её убирает; пока Claude работает, её не видно.
- Подсказки на том языке, на котором пишете вы, и про то, что только что произошло: файл, тест, функция.
- Не помещаются в ширину — встают столбиком.

**Расход:** один вызов Haiku после каждого ответа длиннее 40 символов — примерно 2–3 тысячи токенов на входе и до 200 на выходе. Не вызывается после коротких ответов, ходов субагентов и пока работают фоновые агенты.

**Команды:** `/next` — состояние, `/next off` — выключить (Haiku больше не вызывается, запоминается между сессиями), `/next on` — включить.

**Читает:** последние сообщения сессии. **Сеть:** вызов Haiku через Claude Code — тот же аккаунт и тот же API, что у самого Claude Code. **Хранит:** только флаг «выключено» в хранилище Claude Code.

Установка — в [общем README](../../README.ru.md#установка).
