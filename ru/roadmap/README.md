# 🗺️ roadmap — дорожная карта задачи

Панель «Дорожная карта»: этапы текущей задачи сверху вниз, отмечаются сами по тому, что делает Claude.

```
ЗАДАЧА                              ● Claude работает · 6 мин
сделай страницу входа
━━━━━━━━━━━━──────────  2 из 4

✓ Подготовка контекста                                1 мин
  прочитано 6 файлов · 14 действий
● Выполнение задачи                                   4 мин
  3 файла: login.tsx, api.ts, styles.css
  ✓ Сверстать форму
  ● Подключить API
○ Тест
○ Пуш
```

**Как определяются этапы:**

| Этап | Что его отмечает |
| --- | --- |
| Подготовка контекста | Чтение файлов, поиск, веб, агенты, команды только для чтения (`git status`, `ls`, `gh pr view`…) |
| Выполнение задачи | Правка файлов и прочие команды |
| Проверка | `tsc`, линтеры, `validate`, `build`, `git diff` |
| Тест | `npm test`, `pytest`, `jest`, `vitest`, `claude plugin test`… — при ошибке этап краснеет |
| Пуш | `git commit` (в процессе), затем `git push` (готово) |
| Деплой | `vercel`, `netlify`, `wrangler`, `firebase deploy`, `npm run deploy`, `docker push`… |

- **Новая задача** — каждый ваш новый запрос. Короткие «да», «давай», «продолжай» продолжают текущую. Прошлые задачи уходят в блок «Ранее».
- **Этапы подстраиваются под проект:** «Пуш» — только в git-репозитории, «Деплой» — если есть настройки деплоя, «Проверка» и «Тест» — если они есть в проекте. Если этап всё же случился, он показывается всегда.
- **План Claude:** если Claude ведёт список шагов, он появляется под «Выполнением» с галочками.
- **Статус в шапке:** «Claude работает», «Готово · ждёт вас» или «Есть ошибка».

**Команды:** `/roadmap` — открыть, `/roadmap reset` — новая задача. Панель открывается сама при старте сессии.

**Читает:** ваши запросы (для названия задачи) и вызовы инструментов в сессии; проверяет, есть ли в проекте файлы вроде `package.json`. **Запускает:** `git rev-parse`. **Сеть:** нет.
