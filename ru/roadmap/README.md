# 🗺️ roadmap — дорожная карта задачи

Панель «Дорожная карта»: этапы текущей задачи сверху вниз, отмечаются сами по тому, что делает Claude.

```
сделай страницу входа                                 ↺  ⤓
Claude работает · этап 3 из 4 · 6 мин

◉ ЭТАПЫ                                             2/4
  ✓ Подготовка контекста                           1 мин
  │ прочитано 6 файлов · 14 действий
  ✓ Выполнение задачи                              4 мин
  │ 3 файла: login.tsx, api.ts, styles.css
  ● Тест                                          <1 мин
    npm test
  ○ Пуш

☰ ПЛАН                                              2/5
  ✓ 2 шага выполнено
  ● Подключить API
  ○ Стили
  ○ Документация

◷ РАНЕЕ                                               3
  Показать 3
```

**Как определяются этапы:**

| Этап | Что его отмечает |
| --- | --- |
| Подготовка контекста | Чтение файлов, поиск, веб, агенты, команды только для чтения (`git status`, `ls`, `gh pr view`…) |
| Выполнение задачи | Правка файлов и прочие команды |
| Проверка | `tsc`, линтеры, `validate`, `build`, `git diff` |
| Тест | `npm test`, `pytest`, `jest`, `vitest`, `claude plugin test`… — при ошибке этап краснеет |
| Пуш | `git commit` (в процессе), затем `git push` (готово) |
| Деплой | `vercel`, `netlify`, `wrangler`, `firebase deploy`, `npm run deploy`, `docker push`… |

- **Шапка** — название задачи и одна строка статуса: «Claude работает», «Готово · ждёт вас» или «Есть ошибка», этап и время.
- **Этапы** — лента сверху вниз: пройденные зелёные, текущий подсвечен, ошибка красная, время справа.
- **План** — если Claude ведёт список шагов, он идёт отдельной карточкой: окно вокруг текущего шага, выполненное сведено в одну строку.
- **Новая задача** — каждый ваш новый запрос. Короткие «да», «давай», «продолжай» продолжают текущую. Прошлые задачи уходят в свёрнутую карточку «Ранее». Кнопка ↺ начинает новую вручную.
- **Этапы подстраиваются под проект:** «Пуш» — только в git-репозитории, «Деплой» — если есть настройки деплоя.
- **Под чатом:** кнопка ⤓ или `/roadmap band` переносит карту полосой над полем ввода — задача и цепочка этапов в одну строку (в узкой — одни значки). ⤢ или `/roadmap pane` возвращает её в панель.

**Команды:** `/roadmap` — открыть, `/roadmap reset` — новая задача, `/roadmap band` / `/roadmap pane` — под чат или в панель. Панель открывается сама при старте сессии.

**Читает:** ваши запросы (для названия задачи) и вызовы инструментов в сессии; проверяет, есть ли в проекте файлы вроде `package.json`. **Запускает:** `git rev-parse`. **Сеть:** нет.
