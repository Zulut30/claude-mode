# ⚡ token-speed — скорость ответа модели

Скорость ответа в токенах в секунду, в строке статуса под полем ввода.

```
⚡ ≈48 ток/с                          во время ответа (оценка)
⚡ 52 ток/с · 1 240 ток за 24 с       после ответа (точно, по данным API)
```

- **Во время ответа** — живая оценка по поступающему тексту, обновляется ~4 раза в секунду. Пока ответ идёт, API не сообщает число токенов, поэтому стоит «≈».
- **После ответа** — точная скорость по счёту токенов от API. Строка остаётся до следующего ответа.
- Время считается с первого куска ответа, поэтому задержка до начала ответа не занижает скорость.
- Оценка сама подстраивается по точным данным прошлых ответов — для русского текста, английского и кода.
- Учитывается только основной ответ; параллельные субагенты не смешиваются.

Если модель долго думает, а текст размышлений не приходит, живая оценка будет занижена; итоговая цифра точная.

**Команд нет.** **Читает** только поток ответа модели. **Ничего не запускает** и не ходит в сеть.
