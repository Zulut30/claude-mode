# ⚡ token-speed — скорость ответа модели

Скорость ответа в токенах в секунду, в строке статуса под полем ввода.

```
⚡ ≈48 ток/с ▂▄▆                              во время ответа: за последние 2 секунды
⚡ 52 ток/с ▂▄▆▅▇ · 3 400 ток за 1 мин 5 с   после: средняя за ход, точно по API
```

- **Во время ответа** — живая оценка по тексту за последние 2 секунды, обновляется ~4 раза в секунду. Пока ответ идёт, API не сообщает число токенов, поэтому стоит «≈».
- **После ответа** — средняя скорость за весь ход по точному счёту токенов от API: ход Claude состоит из многих шагов, и считается их сумма, а не последний шаг.
- **Мини-график ▂▄▆▅▇** — скорость последних шагов хода; шаги короче 40 токенов в него не попадают.
- Время считается с первого куска ответа, поэтому задержка до начала ответа не занижает скорость.
- Оценка сама подстраивается по точным данным прошлых ответов (кроме ответов с размышлениями) — для русского текста, английского и кода.
- Учитывается только основной ответ; параллельные субагенты не смешиваются.

Если модель долго думает, а текст размышлений не приходит, живая оценка будет занижена; итоговая цифра точная. Если ответ прервать, строка не зависает: остаётся итог хода.

**Команд нет.** **Читает** только поток ответа модели. **Ничего не запускает** и не ходит в сеть.
