# 📊 usage-band — контекст, лимиты, скорость и кэш

Полоса над полем ввода: ровные колонки, подпись сверху, значение снизу. Если все не помещаются в ширину, встают в два одинаковых ряда. Делит место с другими модами: дорожная карта «под чатом» и подсказки «Дальше» встают ниже.

```
КОНТЕКСТ                   ПАМЯТЬ                  5 ЧАСОВ
42% ━━━━──── 84k/200k      2 файла ~2k ток.        24% ━━────── ↻ 2 ч 15 мин

НЕДЕЛЯ                     СКОРОСТЬ                КЭШ
91% ━━━━━━━─ ↻ 3 д 4 ч     52 ток/с ▂▄▆▅▇ 3 400 ток 42 мин ━━━───── из 1 ч
```

- **Контекст** — сколько контекстного окна занято, в процентах и токенах.
- **Память** — сколько файлов памяти загружено (CLAUDE.md, автопамять) и сколько они весят.
- **5 часов и неделя** — расход лимитов подписки и время до сброса. Появляются после первого ответа модели в сессии.
- **Скорость** — токены в секунду. Во время ответа — живая оценка (≈, синим), после — средняя за ход по точному счёту API и мини-диаграмма скоростей шагов.
- **Кэш** — сколько осталось «тёплому» кэшу переписки (у подписки — час с последнего запроса, иначе 5 минут; срок берётся из ответа API). Пока кэш тёплый, следующее сообщение не обрабатывает всю переписку заново: быстрее и меньше тратит лимиты. Под конец цифра желтеет и краснеет, потом — «остыл · 84k заново»: столько токенов следующее сообщение обработает с нуля.

Цвет: до 70% зелёный, 70–89% жёлтый, от 90% красный. Расход берётся из Claude Code только когда он сам сообщает об изменении, скорость обновляется раз в секунду — мод почти не нагружает приложение.

**Команд нет** — полоса появляется сама. **Читает** цифры сессии и поток ответа модели. **Ничего не запускает** и не ходит в сеть.
